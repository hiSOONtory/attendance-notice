사용 안내

⚠️ e알리미를 사용하는 학교에서만 쓸 수 있어요. 문자는 이 페이지가 직접 보내지 않고, e알리미에서 붙여넣어 보내요.

처음 한 번

  1. 명단 관리에서 학생 명단 엑셀을 올리거나 한 명씩 넣어요. 엑셀은 첫 줄에 번호 / 이름 칸만 있으면 돼요. 전입생도 여기서 추가하고, 이름이나 번호도 바로 고칠 수 있어요.
  2. 이 페이지를 연 같은 브라우저(크롬 또는 엣지)에서 e알리미에 미리 로그인해 두세요. 2차 인증이 나오면 안내에 따라 인증하면 돼요. 다른 브라우저에 로그인돼 있으면 열린 창에서 다시 로그인해야 해요.

보낼 때

  1. 학생 → 구분(지각·도착·조퇴·결과) → 종류(미인정·질병) → 교시를 누르면 문구가 만들어져요. 필요하면 직접 고쳐도 돼요.
  2. 학생이 등교하지 않았고 연락도 안 되면 학생 → 미등교만 누르면 돼요.
  3. 잘못 눌렀으면 같은 버튼을 한 번 더 누르면 취소돼요. ↺ 다시 고르기를 누르면 처음부터 다시 고를 수 있어요.
  4. 복사하고 e알리미 열기를 누르면 문구가 복사되고 e알리미 문자 보내기 화면이 열려요.
  5. e알리미에서 받는 학생을 고르고, 내용 칸에 Ctrl + V로 붙여넣은 뒤 보내요.

알아두세요

  • 보내기 전에 e알리미에서 받는 학생 이름을 한 번 더 확인해 주세요.
  • 명단과 설정은 이 PC의 이 브라우저에만 저장돼요. 다른 PC나 다른 브라우저에서는 다시 올려야 하고, 브라우저 기록(사이트 데이터)을 지우면 함께 지워져요.
  • e알리미 로그인이 풀리면 열린 창에서 다시 로그인(필요하면 2차 인증)한 뒤, 버튼을 한 번 더 누르면 돼요.
  • 엑셀 불러오기와 글꼴에는 인터넷 연결이 필요해요.
  • 여러 사람이 쓰는 PC라면 학년이 끝난 뒤 명단 관리에서 학생을 지워 주세요.
