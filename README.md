# 📨 출결 알림 (e알리미 연동)

지각 · 조퇴 · 결과 · 미등교 상황을 **클릭 몇 번으로 보호자 안내 문자로 만들어 주고**, 복사와 함께 e알리미 문자 보내기 화면을 열어 주는 담임용 도구입니다.

> ⚠️ **e알리미를 사용하는 학교에서만 활용할 수 있어요.**
> 문자는 이 도구가 직접 보내지 않고, 선생님이 e알리미에서 붙여넣어 보냅니다.

- **바로가기:** https://hisoontory.github.io/attendance-notice/
- 설치 없이 HTML 한 장으로 동작하고, 외부 전송이나 AI를 쓰지 않아요.

---

## 이렇게 써요

1. **학생**을 누르고
2. **구분**(지각 · 도착 · 조퇴 · 결과 · 미등교)을 고르고
3. 지각 · 조퇴 · 결과는 **종류**(미인정 · 질병)를 고르고
4. **교시**를 누르면 문구가 완성돼요.
   - 지각: 학생이 들어온 교시 (3 → "3교시 중간에 등교")
   - 조퇴: 마지막으로 들은 교시 (3 → "3교시 후 조퇴")
   - 결과: 빠진 교시를 모두 (3·4 → "3~4교시")
   - 도착: 수업을 듣기 시작하는 교시 (3 → "3교시부터 수업에 참여")
5. **복사하고 e알리미 열기**를 누르면 문구가 복사되고 e알리미 문자 보내기 화면이 열려요.
6. e알리미에서 받는 학생을 고르고 **Ctrl + V**로 붙여넣어 보내면 끝!

잘못 눌렀으면 같은 버튼을 한 번 더 누르거나 **↺ 다시 고르기**를 누르면 돼요.

## 만들어지는 문구 예시

| 상황 | 문구 |
|---|---|
| 질병지각 | 안녕하세요, 보호자님. 오늘 시연이가 병원 진료 후 3교시 중간에 등교했습니다. 질병지각 처리를 위해 나이스 학부모서비스에서 증빙서류(진료확인서 또는 처방전 등)를 첨부하여 출결 신청 부탁드립니다. 감사합니다. |
| 질병조퇴 | 안녕하세요, 보호자님. 오늘 시연이가 병원 진료를 위해 3교시 후 조퇴했습니다. 진료 후 질병조퇴 처리를 위해 나이스 학부모서비스에서 증빙서류(진료확인서 또는 처방전 등)를 첨부하여 출결 신청 부탁드립니다. 감사합니다. |
| 미인정지각 | 안녕하세요, 보호자님. 오늘 시연이가 별도의 사유 없이 3교시 중간에 등교하여 미인정지각으로 처리될 예정입니다. 질병 등 다른 사유가 있으시면 담임에게 연락 부탁드립니다. 감사합니다. |
| 도착 | 안녕하세요, 보호자님. 오늘 시연이가 학교에 도착하여 2교시부터 수업에 참여합니다. 감사합니다. |
| 미등교 | 안녕하세요, 보호자님. 현재 시연이가 등교하지 않았고 아이와도 연락이 닿지 않아 문자드립니다. 확인 후 담임에게 연락 부탁드립니다. 감사합니다. |

- 이름은 성을 빼고 받침에 맞춰 불러요. (이시연 → 시연이가, 지유 → 지유가)
- 미리보기 칸에서 문구를 직접 고친 뒤 복사할 수도 있어요.

## 처음 한 번 준비

1. **명단 관리**에서 학생 명단을 넣어요.
   - 엑셀로 한 번에: 첫 줄에 `번호 / 이름` 칸만 있으면 돼요. → [학생명단_양식.csv](학생명단_양식.csv)
   - 한 명씩 직접 추가 · 수정 · 삭제도 돼요. (전입생 추가 OK)
   - 먼저 써 보고 싶으면 첫 화면의 **예시 명단으로 체험하기**를 누르세요. 드림캐쳐 멤버(지유 · 수아 · 시연 · 한동 · 유현 · 다미 · 가현)가 들어가요.
2. 이 페이지를 연 **같은 브라우저**(크롬 또는 엣지)에서 e알리미에 미리 로그인해 두세요.
   **2차 인증**이 나오면 안내에 따라 인증하면 돼요.

## 개인정보

- 학생 명단은 **선생님 PC의 브라우저 안에만** 저장돼요. 어떤 서버로도 보내지 않아요.
- 보호자 연락처는 필요 없어요. (연락처는 e알리미에 이미 있으니까요.)
- 문자 내용에는 학생 이름(성 제외)과 출결 사실만 들어가요.
- 여러 사람이 쓰는 PC라면 학년이 끝난 뒤 명단 관리에서 학생을 지워 주세요.
